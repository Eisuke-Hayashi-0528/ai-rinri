# AIでやればすぐでしょ（試作）

企業研修のための、AI倫理を体験するブラウザゲームです。
上司に「AIとか使えばすぐできるんでしょ？」と頼まれた仕事をAIで片付けようとする中で、小さな操作の違いが仕事の失敗につながる結末を体験します。

**遊ぶ：** https://eisuke-hayashi-0528.github.io/ai-rinri/

- PC・タブレット・スマホのブラウザで遊べます。ログインや登録は不要です。
- 登場する会社・人物・データはすべて架空です。ゲーム内のAIは本物のAIにはつながっていません。
- 今は試作の段階で、結末は3つ（行動1・行動2・仮の結末）です。

## 開発する人へ

```bash
npm install
npm run dev
```

- 場面・メール・AIの返答・結末などの文章は `data/` にあります。
- `main` に送ると、GitHub Actions で書き出されて GitHub Pages に公開されます。
